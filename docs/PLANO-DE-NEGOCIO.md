# Plano de negócio — Meu Funcionário

## Para quem
Franqueados do Mais Delivery em outras cidades, que hoje fazem na mão:
cadastro de lojas, cardápios, fotos, taxas, motoboys e divulgação.

## Formatos de venda
1. **Serviço (começar por aqui):** a gente opera a cidade do franqueado com as skills.
   Cobrança por loja cadastrada ou pacote de implantação/inauguração.
2. **Plugin do Claude Code:** para franqueados mais técnicos (ou a equipe).
   Instala pelo marketplace; licença validada num servidor nosso.
3. **Extensão Turbo Cardápio:** o que se provar estável vira botão.
   Assinatura mensal; é o formato mais fácil para o franqueado comum.

## Proteção
A parte valiosa (regras, ferramentas, IA) fica num servidor com chave de
licença (MCP remoto / edge function). O plugin e a extensão só chamam esse
servidor. Sem licença ativa, nada funciona.

## O que o franqueado precisa (plugin)
Claude Code + assinatura do Claude, extensão Claude in Chrome, login no painel.

## Riscos
- O painel é da franqueadora: automatizar pode esbarrar no contrato ou quebrar
  com mudanças no sistema. **Sondar a central antes de vender**; parceria é o ideal.
- Marca "Mais Delivery" no nome comercial só com autorização.
